Terminal apps

終端機 app

The terminu family: terminal UIs you can use without reading the docs. Every app runs on the same keys, Tab Enter Esc Space ? q, and when in doubt, press Space.

terminu family：不看文件就能用的終端機介面。每個 app 都用同一組按鍵，不確定的時候，就按 Space。

~ $ boxu

boxu

Every container runtime in one terminal screen: the containers, images, networks and volumes of Apple container, Docker, Podman, containerd and CRI-O in the same lists, and their logs side by side.

每一種 container runtime，都在同一個終端機畫面裡：Apple container、Docker、Podman、containerd、CRI-O 的 container、image、network、volume 列在同一份清單，log 也能並排看。

gittu

A git client for the terminal: the branches beside the history graph, everything you can do in the Space menu.

終端機的 git 工具：左邊是分支，右邊是分支圖，能做的事都在 Space 選單裡。

github.com/vulcanshen/gittuREADME-zh_TW.md

tetru

A falling-block game for the terminal: move and turn the pieces as they fall, fill a row to clear it, and set the keys to suit your hands.

在終端機裡玩的落塊消行遊戲：趁方塊落下時移動、旋轉，排滿一整行就消掉，按鍵也能照自己的習慣改。

github.com/vulcanshen/tetruREADME-zh_TW.md

終端機裡看檔案的工具：Markdown 畫成文件、mermaid 畫成圖，其他檔案照它的顏色。

Build your own terminu app

自己做一個 terminu app

terminu design terminu-go terminu-harness
+ Claude Code Build with Claude Code Hit a problem Open an issue Release your app
  1. 01

    Design language

    terminu design

    The keys and screens every terminu app shares.

    每個 terminu app 共用的按鍵與畫面設計原則。

  2. 02

    Go library

    terminu-go

    Draws and drives a terminal UI the way terminu design says.

    照 terminu design 畫出並驅動終端機介面的 Go 函式庫。

  3. 03

    Claude Code plugin

    terminu-harness

    Builds a TUI app with terminu design and terminu-go, from what you want to a finished app.

    照 terminu design、用 terminu-go 做 TUI app 的 Claude Code plugin，從想法一路做到完成。

  4. 04

    Your app

    Build with Claude Code

    Describe what you want; Claude Code builds it with terminu-harness.

    說出你要什麼，Claude Code 就用 terminu-harness 把它做出來。

  5. ✓

    Your app

    Release your app

    When it's ready, ship it. That's the way out of the loop.

    做好了就發布，這就是離開循環的出口。

  6. 05

    Feedback

    Hit a problem

    Something in the design, the library or the plugin gets in your way.

    設計原則、函式庫或 plugin 有地方卡住你。

  7. 06

    Feedback

    Open an issue

    Report it on terminu. The fix comes back round through all three.

    到 terminu 回報，修正會一路回到這三個專案裡。
