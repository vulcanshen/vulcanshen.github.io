Terminal apps

終端機 app

terminu

The terminu family: terminal UIs you can use without reading the docs. Every app runs on the same keys, Tab Enter Esc Space ? q, and when in doubt, press Space.

terminu family：不看文件就能用的終端機介面。每個 app 都用同一組按鍵，不確定的時候，就按 Space。

tetru

A falling-block game for the terminal: move and turn the pieces as they fall, fill a row to clear it, and set the keys to suit your hands.

在終端機裡玩的落塊消行遊戲：趁方塊落下時移動、旋轉，排滿一整行就消掉，按鍵也能照自己的習慣改。

catu

A file viewer for the terminal: Markdown drawn as a document, mermaid as diagrams, any other file in colour.

終端機裡看檔案的工具：Markdown 畫成文件、mermaid 畫成圖，其他檔案照它的顏色。

ccdrawu

A sidebar and status line for Claude Code: usage limits, context, cost, git and session stats beside the transcript or under the prompt.

Claude Code 的側邊欄與狀態列：用量上限、context、花費、git 與 session 統計，放在對話旁邊或輸入框下方。

locku

A screensaver with a PIN lock, for the terminal, wired into tmux and screen.

終端機的螢幕保護程式加 PIN 鎖，接得上 tmux 與 screen。

webu

A terminal browser that reads a web page as a document.

把網頁當一份文件來讀的終端機瀏覽器。

sshu

A terminal front end for ssh and sftp: hosts, many live sessions on one screen, and two-sided file transfer.

ssh 與 sftp 的終端機前端：host 收在一處、多個 shell 並排、兩台機器之間直接搬檔案。

filu

A terminal file manager you don't have to learn: mark, copy and move across tabs, find by name or content, preview as you go.

不用學的終端機檔案管理器：收集檔案再放到別處、依檔名或內容找東西、邊走邊預覽。

kbu

A single-pane Kubernetes workspace: relatives navigation, YAML compare, and a persistent shell built in.

終端機裡的一頁式 Kubernetes 工作區：跟著關聯走、比對 YAML，還內建一個不會斷的 shell。

hostu

Switch the hosts file between profiles, in the terminal: the office, home, a client's site, one key each.

在終端機裡用 profile 切換 hosts 檔：公司、家裡、客戶現場，按一個鍵就換過去。
