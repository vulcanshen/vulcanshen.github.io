支援

用中世紀的熙篤會數字顯示時間。

Ciscrux 是免費的 macOS 螢幕保護程式，用熙篤會（Cistercian）數字顯示年、日期、時間和秒，每一個都只是一個符號。

聯絡

要回報問題或提問，請到 GitHub 開一個 issue。沒有 GitHub 帳號的話，請寄信到 vulcan.shen.2304@gmail.com。如果有東西不正常，請附上 Ciscrux 的版本（在選項視窗的左下角）、你的 macOS 版本，以及你的 Mac 是 Apple 晶片還是 Intel 處理器。

開始使用

  1. 從 GitHub 下載 Ciscrux.zip，打開它。
  2. 雙擊 Ciscrux.saver。macOS 會問是否要安裝這個螢幕保護程式，按「安裝」。
  3. 打開「系統設定」›「背景圖片」›「螢幕保護程式⋯」，選 Ciscrux。
  4. 按 Ciscrux 旁邊的「選項⋯」，可以調整要顯示的內容。

找不到螢幕保護程式的設定

新版 macOS 的「系統設定」側邊欄裡，沒有螢幕保護程式自己的項目：要打開「背景圖片」，再按下方的「螢幕保護程式⋯」。舊版 macOS 則在「系統設定」（或「系統偏好設定」）裡找「螢幕保護程式」。

Ciscrux 要錢嗎？

不用。Ciscrux 可以免費下載與使用，不用購買，也不用訂閱。

這些符號怎麼讀？

每個符號是一條直線，四周最多有四個記號：右上是個位、左上是十位、右下是百位、左下是千位。四個角落都用同一組記號表示 1 到 9，只是左右或上下翻轉過來；0 就留白。Ciscrux 依序顯示年、日期（月和日）、時間（24 小時制的時和分）和秒。還在學的時候，可以打開 Show Hint，在每個符號下方顯示一般的數字。到 Ciscrux 的頁面試試看。

秒的符號下半部是什麼？

右下是星期幾，星期一是 1、星期日是 7；左下是月相，新月是 1，一直到殘月是 8。打開 Show Hint 時，秒的左邊有一個小月亮表示月相，右邊則是當天的行星符號。一週七天自古就各對應一顆星：星期一是月亮 ☽、星期二是火星 ♂︎、星期三是水星 ☿、星期四是木星 ♃、星期五是金星 ♀︎、星期六是土星 ♄、星期日是太陽 ☉。

各個選項是做什麼的？

選項視窗目前只有英文，下面照畫面上的名稱列出。

  • Line thickness：線條粗細，以符號高度的百分比計算，1–15%，預設 5%。
  • Show Hint：在每個符號下方顯示一般的數字。預設關閉。
  • Show Year (YYYY)、Show Month / Day (MMDD)、Show Seconds | Moon phase | Weekday：分別打開或關掉年、日期和秒。時間一定會顯示。
  • Layout：Horizontal 把所有符號排成一列。Stacked 分成上下兩列：四個符號時排成 2×2，兩個或三個時把時間放在上面。
  • Animation：Stroke 一筆一筆畫出新符號，Fade 淡入淡出，None 直接切換。
  • Background color、Stroke color、Hint color：背景、符號，以及符號下方數字的顏色。
  • Restore Defaults：把所有選項恢復成預設值，按 OK 才會套用。

怎麼更新或移除 Ciscrux？

要更新時，下載最新的 Ciscrux.zip，用同樣的方式再安裝一次。用 Homebrew 的話，安裝用 brew install --cask vulcanshen/tap/ciscrux，更新用 brew upgrade --cask ciscrux。更新後如果看到的還是舊版，請重新開機，或登出再登入一次：執行過的螢幕保護程式可能還留在記憶體裡。

要移除時，到 ~/Library/Screen Savers 刪掉 Ciscrux.saver；如果當初是裝給所有使用者，則在 /Library/Screen Savers。在 Finder 選「前往」›「前往檔案夾⋯」，貼上路徑就能打開這個資料夾。用 Homebrew 的話，執行 brew uninstall --cask ciscrux。

隱私

Ciscrux 沒有任何連網的程式碼，也不收集任何資料，只把選項存在你的 Mac 上。詳見隱私權政策。

系統需求

macOS 11 以上，Apple 晶片或 Intel 處理器的 Mac 都可以。
