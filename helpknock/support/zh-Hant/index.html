支援

沒有網路，也能被找到。

災難中沒有網路時，讓每支手機成為一個藍牙「燈塔節點」—— 受困者被發現、被辨識身分、能與救災人員溝通的近距離救援 App。

這不是緊急救援專線的替代。只要還有訊號，請先打當地的緊急電話。

聯絡

回報問題或提問，請到 GitHub 開一個 issue，標題開頭加上 [HelpKnock]。沒有 GitHub 帳號的話，請寄信到 vulcan.shen.2304@gmail.com。如果遇到問題，請附上 iPhone 或 iPad 的型號與 iOS 版本。

開始使用

  1. 趁平常把資料填好、選好要分享什麼。
  2. 允許藍牙、定位、「動作與健身」與「區域網路」。
  3. 真的出事時，打開 app、點「我需要幫助」。

HelpKnock 要錢嗎？

不用。所有功能都免費；設定裡的「支持開發者」是自願的，不會解鎖任何東西。

對方的手機也要裝 HelpKnock 嗎？

要。雙方的手機都要裝 HelpKnock，並且開著藍牙。

藍牙傳得多遠？

藍牙只傳得到很短的距離，隔牆、隔瓦礫會更短。

可以把 app 關掉嗎？

不要在多工畫面把 HelpKnock 滑掉：iOS 不會再把它打開，別人就找不到你。重開機後要再打開一次。

隱私

HelpKnock 沒有伺服器、沒有帳號。你輸入的資料留在你的手機上，只透過藍牙給附近的手機、經由同一個 Wi-Fi 給救災人員。詳見隱私權政策。

系統需求

iOS 18.6 或更新版本的 iPhone 或 iPad，並且開著藍牙。
