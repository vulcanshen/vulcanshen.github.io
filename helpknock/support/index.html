Support

Be found without a network.

When a disaster takes the network down, HelpKnock turns each phone into a Bluetooth beacon: a short-range rescue app that helps trapped people be found, be identified and talk with rescuers nearby.

Not a replacement for emergency services. If you have any signal, call 119 or your local emergency number first.

Contact

To report a problem or ask a question, open an issue at github.com/vulcanshen/vulcanshen.github.io/issues and start the title with [HelpKnock]. A GitHub account is needed.

Privacy

HelpKnock has no server and no account. Read the privacy policy.

Requirements

iPhone or iPad with iOS 18.6 or later, and Bluetooth turned on.

支援

沒有網路，也能被找到。

災難中沒有網路時，讓每支手機成為一個藍牙「燈塔節點」—— 受困者被發現、被辨識身分、能與救災人員溝通的近距離救援 App。

這不是緊急救援專線的替代。只要還有訊號，請先打 119 或當地的緊急電話。

聯絡

回報問題或提問，請到 github.com/vulcanshen/vulcanshen.github.io/issues 開一個 issue，標題開頭加上 [HelpKnock]，需要 GitHub 帳號。

隱私

HelpKnock 沒有伺服器、沒有帳號。請看隱私權政策。

系統需求
