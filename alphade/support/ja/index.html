サポート

ロゴの下にあったものを取り戻す。

Alphade は、動画の半透明の透かし、ロゴ、文字のオーバーレイを Mac 上で取り除きます。ぼかしてごまかすのではなく、下にあった元の映像を取り戻します。

お問い合わせ

問題の報告やご質問は、GitHub で issue を作成してください。GitHub アカウントをお持ちでない場合は、vulcan.shen.2304@gmail.com までメールでお送りください。うまく動かないときは、macOS のバージョンと動画の形式・サイズ（例：MP4、1920 × 1080）を添えて、できればスクリーンショットも付けてください。

使いかた

  1. 動画を開きます。サイドバーの「動画を選択…」をクリックするか、動画をウインドウにドラッグします。
  2. 画面上で透かしを囲むように枠をドラッグします。ハンドルをドラッグすると調整できます。
  3. 「解析」をクリックします。結果には「きれいに除去可能」「除去可能（背景で埋める）」「除去後にぼやける」のいずれかが表示されます。
  4. 結果を確認します。「オリジナル」「処理後」「比較」を切り替えたり（⌘1〜⌘3）、O キーを押している間オリジナルを表示したり、矢印キーで 1 フレームずつ移動したり、スペースキーで現在のフレームから再生したりできます。枠を描いたあとは 2 倍や 4 倍に拡大することもできます。
  5. コーデック（H.264 または HEVC）と解像度を選び、「書き出す…」をクリックして保存先を選びます。

人物や文字など、実際の被写体が枠の中を通る場合は、「詳細設定」を開いて、細部を残したい範囲を指定してください。

Alphade は無料ですか？

はい。Alphade は無料でダウンロードして使えます。購入も、試用の制限も、サブスクリプションもありません。

インストールするには？

GitHub から zip をダウンロードして開き、Alphade を「アプリケーション」フォルダにドラッグします。初めて開くときに、インターネットからダウンロードしたアプリを開くかどうか macOS に確認されるので、「開く」をクリックしてください。Alphade は Developer ID で署名され、Apple の公証を受けています。アップデートするときは、同じ方法で最新版をダウンロードして、古いものと置き換えてください。

Homebrew の場合は brew install --cask vulcanshen/tap/alphade でインストールし、brew upgrade --cask alphade でアップデートします。

アンインストールするには？

Alphade をゴミ箱にドラッグします。設定と一時ファイルは ~/Library/Containers/app.vulcanshen.alphade にあり、こちらも削除できます。Homebrew でインストールした場合は brew uninstall --cask alphade を実行してください。--zap を付けると、設定と一時ファイルも削除されます。

どんな透かしを除去できますか？

動画の最初から最後まで同じ位置にある、半透明の透かし、ロゴ、文字です。不透明なロゴも、背景が単色・グラデーション・スライドのように単純なら、周囲の背景で埋められます。動く透かしや、細かい背景・実写映像の上にある不透明な透かしには対応していません。

「きれいに除去可能」「除去可能（背景で埋める）」「除去後にぼやける」とは？

  • きれいに除去可能：透かしがどのように重ねられたかを Alphade が割り出せたので、透かしの下にある内容も残ります。
  • 除去可能（背景で埋める）：透かしの部分は周囲の背景で埋めます。下にあった内容は失われますが、背景が単純なら跡は目立ちません。
  • 除去後にぼやける：細かい背景の上を埋める必要があるため、埋めた部分が目立ちます。

動画が開けないのはなぜですか？

Alphade が開けるのは 8 ビット（SDR）の MP4、MOV、M4V 動画です。10 ビットや HDR の動画（HDR をオンにして撮影した iPhone の動画の多くなど）には、まだ対応していません。

言語を切り替えるには？

Alphade は英語、ドイツ語、スペイン語、フランス語、日本語、韓国語、繁体字中国語に対応していて、特に選ばなければ Mac の言語で表示されます。切り替えるには、サイドバー下部の歯車をクリックするか「Alphade › 設定」を選び、「一般」で言語を選んでから Alphade を再起動してください。

プライバシー

Alphade の処理はすべて Mac 上で行われます。動画がアップロードされることはなく、データも一切収集しません。詳しくはプライバシーポリシーをご覧ください。
