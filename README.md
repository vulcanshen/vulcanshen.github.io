# vulcanshen.github.io

vulcan 的 app 支援頁與隱私權政策，用 GitHub Pages 發布：<https://vulcanshen.github.io/>

| App | 支援頁 | 隱私權政策 |
|---|---|---|
| Alphade | <https://vulcanshen.github.io/alphade/> | <https://vulcanshen.github.io/alphade/privacy.html> |

App Store Connect 的「支援網址」與「隱私權政策網址」填的就是該 app 的這兩個網址。

## 加入一個 app

- 每個 app 一個資料夾，名稱用小寫的 app 名稱，裡面放 `index.html`（支援頁）與 `privacy.html`（隱私權政策）。
- 中英文寫在同一頁，分成 `#en` 與 `#zh-Hant` 兩段，頁首放切換兩種語言的連結。
- 共用根目錄的 `style.css`（頁面裡寫 `../style.css`）。
- 在根目錄 `index.html` 的 app 清單與上面的表格各加一行。
- 隱私權政策改了，最後更新日期一起改。
